# Tags — protótipo navegável

Abra `index.html` no navegador; não precisa de servidor nem dependências. Use Baralhos e Cartões para ver as tags nas listas, selecione várias para combinar filtros e abra Detalhe para conferir tags do baralho e de seus cartões. Os formulários permitem adicionar tags com Enter e remover antes de salvar.

Os dados são fictícios e vivem apenas na aba. O protótipo demonstra interação e hierarquia visual; não se conecta à aplicação nem persiste após recarregar.

O verificador Playwright pode ser executado com `rtk proxy node design/tags/verificar.mjs` a partir da raiz do projeto.
