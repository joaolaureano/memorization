# Protótipo: importação de baralho Anki

Abra `index.html` diretamente no navegador. Escolha qualquer arquivo `.apkg` para avançar à prévia demonstrativa. Os cartões e os nomes podem ser editados; o conteúdo mostrado é ilustrativo e não é enviado nem salvo.

O layout se adapta a telas estreitas e largas. O fluxo real da aplicação lê o pacote no servidor e só persiste após a confirmação.
